# GCWB email assets

Public images for Get Clients With Books emails, served by GitHub Pages at
https://garyw23gcwb.github.io/gcwb-email-assets/

Everything here is public: only add images that appear in emails. Built and
published by Claude from `Projects/gcwb-email-templates` in the client-brain
repo. Never rename or delete a file that a live email uses: add a new file
instead.

- `email/header-paperback.jpg`: the standard branded email header (paperback
  3D mockup on the light gradient), 1104 x 480, shown at 552 x 240.
